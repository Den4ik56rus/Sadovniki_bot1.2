# Новые правила логики формирования ответа

**Дата:** 2026-02-15
**Версия:** 1.2.3
**Миграция:** schema_47_answer_logic_section.sql

## Обзор изменений

Добавлена новая базовая секция промпта `answer_logic` с тремя ключевыми правилами для улучшения качества ответов LLM.

## Три новых правила

### 1. Фильтрация знаний по культуре

**Проблема:** LLM использовала чанки из базы знаний даже если они относятся к другой культуре.

**Решение:**
- КРИТИЧЕСКИ ВАЖНО: Если паспорт чанка в секции базы знаний НЕ ПОДХОДИТ к текущей культуре консультации — ИГНОРИРОВАТЬ этот чанк полностью
- Проверять поле `subcategory` в чанках: должно совпадать с культурой консультации
- Использовать ТОЛЬКО чанки текущей культуры или категории "общее"/"универсальное"

**Пример:**
- Культура консультации: "малина ремонтантная"
- Чанк помечен: "клубника"
- Действие: НЕ использовать этот чанк

### 2. Разбиение сезонных вопросов

**Проблема:** На вопрос "план на весь сезон" LLM давала слишком длинный ответ, перегружая пользователя информацией.

**Решение:**
- При вопросе о плане на весь сезон — РАЗБИТЬ ответ на две части
- В первом ответе — ТОЛЬКО первая половина сезона (весна-начало лета)
- В конце добавить предложение:

  > "Это план для первой половины сезона. Если хотите, могу подробно расписать вторую часть сезона (лето-осень) — просто напишите."

**Примеры вопросов:**
- "план питания на весь сезон"
- "календарь обработок на год"
- "схема защиты с весны до осени"

### 3. Узкие вопросы — узкие ответы

**Проблема:** На узкий вопрос "Чем обработать от клеща?" LLM давала полную схему защиты, а не конкретный ответ.

**Решение:**

**УЗКИЙ ВОПРОС** — касается конкретной обработки/подкормки для:
- определённого вредителя/болезни (например, "от клеща", "от серой гнили")
- определённой цели (например, "для повышения сахаристости")
- определённой фазы развития (например, "в начале цветения")

**ДАВАТЬ ОТВЕТ СТРОГО ПО ВОПРОСУ:**
- Период активности конкретного вредителя/болезни (если применимо)
- Конкретные препараты для ЭТОЙ задачи
- Конкретную фазу/сроки для ЭТОЙ обработки/подкормки
- НЕ УГЛУБЛЯТЬСЯ в общий уход, профилактику, комплексные схемы в первом ответе

**В КОНЦЕ узкого ответа добавить:**

Для категории "защита растений":
> "Защита растений должна состоять из комплексных, взаимосвязанных, профилактических обработок. Если хотите, распишу подробно, как правильно выстроить систему защиты для Вашей культуры."

Для категории "питание растений":
> "Питание растений должно быть комплексным и сбалансированным. Если хотите, распишу подробно, как правильно выстроить систему питания для Вашей культуры."

**Примеры:**

**УЗКИЕ вопросы** (краткий ответ + предложение):
- "Чем и когда обработать малину от клеща?" → ответ ТОЛЬКО про клеща
- "Чем подкормить клубнику для сладости ягод?" → ответ ТОЛЬКО про подкормку для сахаристости
- "Как обработать смородину в начале цветения от тли?" → ответ ТОЛЬКО про тлю в этой фазе

**ШИРОКИЕ вопросы** (полный ответ сразу):
- "Как защитить малину от болезней и вредителей?" → полный план защиты
- "Какое питание нужно клубнике на весь сезон?" → полная схема питания (но только первая половина, см. правило 2)
