# Этап 2: Поддержка (Kanban)

**Статус:** :x: Not Started
**Зависит от:** Этап 1 (Карточка клиента)

---

## Цель этапа

Реализовать правило: кейс появляется только по явному нажатию "Поддержка".

**Выход этапа:** Операционка поддержки заработала.

---

## Требования (высокоуровневые)

### Создание кейса
- Кнопка "Создать кейс поддержки" в топике
- Кнопка "Создать кейс" в карточке клиента
- Кейсы НЕ создаются автоматически

### Kanban этапы
- Новое → В работе → Ждём клиента → Решено → Закрыто
- Drag-and-drop между колонками

### Поля кейса
- Ссылка на топик (опционально)
- Приоритет (low/medium/high/critical)
- Ответственный (из списка админов)
- Дедлайн
- Описание/комментарии

### Уведомления
- Telegram уведомление админу при создании кейса
- Уведомление при назначении на оператора
