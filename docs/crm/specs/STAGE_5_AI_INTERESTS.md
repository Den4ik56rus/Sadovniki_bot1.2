# Этап 5: AI-выдержки интересов клиента

**Статус:** :x: Not Started
**Зависит от:** Этап 3 (Подписки/лимиты/деньги)

---

## Цель этапа

Не "сводка решения", а именно профиль интересов для рассылок.

**Выход этапа:** Появляется основа для "точечной рассылки".

---

## Требования (высокоуровневые)

### Когда запускаем
- При закрытии топика (автоматически)
- По кнопке "Обновить профиль интересов"

### Что сохраняем
- Культура/подкультура
- Категория темы (питание, защита, и т.д.)
- 3–7 тегов интересов (например: "клещ", "хлороз", "pH", "капельный полив")
- Счётчик частот по тегам/культурам

### Блок "Интересы клиента" в карточке
- Топ интересов (теги с частотой)
- Топ культур
- История изменений профиля
