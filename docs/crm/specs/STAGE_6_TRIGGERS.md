## Требования (высокоуровневые)

### Триггеры (включаем по одному)
- Подписка истекает через 3 дня → создать задачу + уведомление админу
- Остаток вопросов < 2 → задача "допродать"
- Неактивность N дней → задача "реактивация"

### Задачи
- Чек-лист (опционально)
- Дедлайн
- Статус: new / in_progress / done / cancelled
- Связь с клиентом/топиком

### Уведомления
- В Telegram админам/операторам
- Настройка получателей по типу триггера

### Защита от спама
- Один триггер = одна задача (дедупликация)
- Cooldown период между повторными триггерами
