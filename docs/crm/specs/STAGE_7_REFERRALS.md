---

## Цель этапа

Учёт рефералов и отдельная вкладка "Рефералы".

**Выход этапа:** Канал роста + аналитика по рефералке.

---

## Требования (высокоуровневые)

### Механика
- Уникальный `referral_code` для каждого клиента
- Start payload фиксирует "кто кого привёл"
- Связь referrer ↔ referee

### Вкладка "Рефералы"
- Список участников программы
- Кто кого пригласил
- Сколько приглашений отправлено
- Сколько активировались (N сообщений)
- Сколько оплатили

### Начисления (варианты)
- Вариант 1: Только учёт (без бонусов на старте)
- Вариант 2: +N вопросов за оплатившего реферала
- Вариант 3: % от оплаты реферала
