## Требования (высокоуровневые)

### Общий дашборд
- Пользователи (всего, новых за период)
- Топики (всего, за период)
- Выручка (total, за период)
- Cost (LLM расходы)
- Маржа

### Воронка первого клиента
- Start → Бесплатный лимит → Оплата
- Конверсии между этапами
- Среднее время прохождения

### Дашборд поддержки
- В очереди (по приоритетам)
- Среднее время ответа
- Просрочки SLA
- Закрыто за период

### Дашборд рефералов
- Регистрации по рефералкам
- Активации
- Оплаты
- Топ рефереров
