### Права доступа
- Роли: админ / модератор / оператор

- Логирование действий по ролям

### Аудит-лог
- Кто поменял статус
- Кто редактировал данные
- История изменений с timestamp

### Экспорт данных
- CSV отчёты по клиентам
- CSV отчёты по покупателям
- CSV отчёты по рефералам
- Фильтры при экспорте
