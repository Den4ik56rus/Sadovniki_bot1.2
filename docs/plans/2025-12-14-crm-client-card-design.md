# CRM: Карточка клиента и Kanban-доска

**Дата:** 2025-12-14
**Статус:** Дизайн утверждён, готов к реализации

---

## Концепция

CRM-система для управления клиентами Sadovniki-bot с Kanban-доской по воронке продаж и полноценными карточками клиентов.

**Пользователь:** владелец продукта (вы)
**Цель:** видеть полный профиль клиентов, управлять воронкой, вести заметки и задачи

---

## Kanban-доска

### Колонки (путь клиента)

| # | Колонка | Триггер попадания |
|---|---------|-------------------|
| 1 | **Новый** | Нажал /start |
| 2 | **Попробовал консультации** | Задал хотя бы 1 вопрос |
| 3 | **Закончился пробный режим** | Исчерпал лимит (будущее) |
| 4 | **Купил** | Оплатил подписку (будущее) |

### Поведение

- **Drag-and-drop** между колонками
- Перетаскивание = принудительная смена статуса в БД
- Автоматические переходы (1→2) + ручные переходы
- В будущем: триггеры при смене статуса (дать доступ, отправить сообщение)

### Карточка в Kanban (компактный вид)

```
┌─────────────────────────┐
│ 👤 Имя + аватар         │
│ 💰 Заплатил: 0 ₽        │
│ 📊 Потрачено: 45 ₽      │
│ ⭐ Free | ∞ дней | 3 вопр│
└─────────────────────────┘
```

**Поля:**
- Имя/username + аватар (Telegram)
- Сколько заплатил (₽) — пока 0, заглушка
- Сколько потрачено на него (LLM cost в ₽)
- Уровень подписки + остаток дней + остаток вопросов — пока заглушки

## Полная карточка клиента

Открывается при клике на карточку в Kanban.

### Шапка карточки

```
┌──────────────────────────────────────────────┐
│ 👤 Иван Петров (@ivan_petr)                  │
│ 📍 Краснодар | 📅 С 15.10.2024               │
│ ⭐ Подписка: Free | Баланс: 0 ₽              │
│ [Изменить статус ▼] [Написать в Telegram]    │
└──────────────────────────────────────────────┘
```

### Вкладки

#### 1. Консультации
- Список всех топиков (как текущий TopicTimeline)
- При клике — разворачивается переписка (как ConsultationView)
- Фильтр по культуре/категории

#### 2. Статистика
- Всего консультаций / токенов / стоимость
- Топ культур (что чаще спрашивает)
- Топ категорий (питание, защита, посадка)
- График активности по времени

#### 3. Платежи
- История платежей (пока пусто, заглушка)
- Текущая подписка и её параметры
- Кнопка "Добавить платёж вручную"

#### 4. Заметки
- Текстовые заметки о клиенте
- Теги (VIP, оптовик, проблемный, etc.)
- Задачи с датами (чек-лист)
- Напоминания

## Технические решения

### Статус клиента в воронке

```sql
CREATE TABLE client_funnel_status (
    user_id INTEGER PRIMARY KEY REFERENCES users(id),
    status VARCHAR(30) NOT NULL DEFAULT 'new',
    -- 'new', 'tried', 'trial_ended', 'paid'
    auto_status VARCHAR(30), -- автоматически вычисленный
    manual_override BOOLEAN DEFAULT false,
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

**Логика:**
- `auto_status` — вычисляется по данным (есть консультации? есть оплата?)
- `status` — может быть переопределён вручную (drag-and-drop)
- `manual_override` — флаг что статус изменён вручную

### Интеграция с существующим

- Переиспользуем `TopicTimeline` и `ConsultationView` во вкладке "Консультации"
- Переиспользуем логику из `StatsPanel` для статистики по клиенту
- Добавляем новый раздел "CRM" в навигацию (рядом с Users, Live, Stats, Documents)
