# Сессия: Добавление правил логики формирования ответа

**Дата:** 2026-02-15
**Версия:** 1.2.3 → 1.2.3 (патч)
**Статус:** ✅ Завершено

## Задача

Добавить три новых правила в системные промпты для улучшения качества ответов LLM:

1. **Фильтрация знаний по культуре** — игнорировать чанки из базы знаний, которые не подходят к текущей культуре консультации
2. **Разбиение сезонных вопросов** — при вопросе о плане на весь сезон давать только первую половину + предложение продолжить
3. **Узкие вопросы — узкие ответы** — на конкретный вопрос (например, "от клеща") давать конкретный ответ, а не полную схему защиты

## Содержимое новой секции answer_logic

```
🟦 ЛОГИКА ФОРМИРОВАНИЯ ОТВЕТА:

1. ФИЛЬТРАЦИЯ ЗНАНИЙ ПО КУЛЬТУРЕ
   КРИТИЧЕСКИ ВАЖНО: Если паспорт чанка в секции базы знаний НЕ ПОДХОДИТ к текущей культуре консультации — ИГНОРИРУЙ этот чанк полностью.
   - Проверяй поле subcategory в чанках: оно должно совпадать с культурой консультации
   - Если культура консультации "малина ремонтантная", а чанк помечен "клубника" — НЕ используй этот чанк
   - Используй ТОЛЬКО те чанки, которые относятся к текущей культуре или к категории "общее"/"универсальное"

2. РАЗБИЕНИЕ СЕЗОННЫХ ВОПРОСОВ
   Если вопрос касается плана на весь сезон:
   - РАЗБЕЙ ответ на две части: ТОЛЬКО первая половина сезона (весна-начало лета)
   - В КОНЦЕ ответа добавь: "Это план для первой половины сезона. Если хотите, могу подробно расписать вторую часть сезона (лето-осень) — просто напишите."

3. УЗКИЕ ВОПРОСЫ — УЗКИЕ ОТВЕТЫ
   Если вопрос узкий (конкретный вредитель/болезнь/цель/фаза):
   - ДАВАЙ ОТВЕТ СТРОГО ПО ВОПРОСУ
   - НЕ УГЛУБЛЯЙСЯ в общий уход, профилактику, комплексные схемы
   - В КОНЦЕ добавь: "Защита растений должна состоять из комплексных, взаимосвязанных, профилактических обработок. Если хотите, распишу подробно, как правильно выстроить систему защиты для Вашей культуры."
```

## Примеры использования

### Пример 1: Узкий вопрос (защита)
**Вопрос:** "Чем и когда обработать малину от клеща?"

**До изменений:** Полная схема защиты малины на весь сезон (2000+ символов)

**После изменений:**
- Период активности клеща
- Конкретные акарициды (Актеллик, Фуфанон)
- Сроки обработки (май, июль)
- ЗАВЕРШЕНИЕ: "Защита растений должна состоять из комплексных, взаимосвязанных, профилактических обработок. Если хотите, распишу подробно, как правильно выстроить систему защиты для Вашей культуры."

### Пример 2: Сезонный вопрос
**Вопрос:** "Дай план питания малины на весь сезон"

**До изменений:** Весь сезон сразу (3000+ символов, перегрузка информацией)

**После изменений:**
- Подробный план: весна → начало лета
- ЗАВЕРШЕНИЕ: "Это план для первой половины сезона. Если хотите, могу подробно расписать вторую часть сезона (лето-осень) — просто напишите."

### Пример 3: Фильтрация по культуре
**Культура консультации:** малина ремонтантная
**Чанк в базе знаний:** subcategory="клубника"

**До изменений:** LLM могла использовать чанк, адаптируя информацию "на лету"

**После изменений:** Чанк ИГНОРИРУЕТСЯ полностью, используются только чанки с subcategory="малина ремонтантная" или "универсальное"
